PHONE-ONLY OCRP COMPILER PACKAGE

1. Create a GitHub repository.
2. Upload all files/folders from this package.
3. Open Actions -> "Compile OCRP Pawn Gamemode" -> Run workflow.
4. When it finishes, open the workflow run and download the "OCRP-AMX" artifact.
5. Extract ocrp.amx.
6. Upload ocrp.amx to your SA-MP server's gamemodes/ folder.
7. Upload server.cfg to the server root.

The server.cfg already contains:
gamemode0 ocrp 1
